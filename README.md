# TP3 — Comunicación en Grupo (Multicast)

Julián Agustín Olivera — Licenciatura en Sistemas de Información, UADER FCyT.

Sistema de comunicación en grupo sobre IP multicast con sockets:

- Atomicidad de los mensajes (o los reciben todos los miembros del grupo, o ninguno).
- Un nodo coordinador central que recibe los mensajes externos al grupo y los reenvía.
- Grupo de tres nodos con dirección de grupo, más una cuarta computadora que envía
  mensajes desde el exterior.
